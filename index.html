AutomatisationN8N

AutomatisationN8N is a personal desktop tool that runs on the owner's Windows computer. It renders short animated videos created by the owner (quizzes, simulations, animated maps) and uploads them to the owner's own TikTok account as drafts. Each draft is reviewed, captioned and posted manually in the TikTok app.

How it works

  1. The owner connects a TikTok account once, through TikTok's official login page (Login Kit, OAuth 2.0 with PKCE).
  2. When a video is ready, the tool sends the file to TikTok with the Content Posting API (video.upload).
  3. The video appears in the TikTok inbox as a draft. Nothing is published automatically.
